# Broodforge

Broodforge is a Discord frontend for Claude Code. The project is design-first: the design docs
come before any code, and there is no application code yet.

## Where to look

- [`docs/README.md`](docs/README.md): the map of the repository.
- [`docs/design/README.md`](docs/design/README.md): the design docs and the ADRs.
- [`docs/HANDOFF.md`](docs/HANDOFF.md): where work stands now and what comes next.

This repository was decanted from the Hatchery base (https://github.com/jasondorjeshort/hatchery)
and keeps its working agreement in [`CLAUDE.md`](CLAUDE.md).
